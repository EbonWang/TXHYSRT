产品介绍

会议结束，字幕即刻到手。

腾讯会议网页版的字幕散落在滚动列表中，手动复制费时又容易遗漏。 字幕导出脚本会自动定位字幕容器、逐屏增量读取，再按你需要的格式一键生成文件， 支持预览、复制、说话人识别与偏好保存。

安装步骤

三步，开始使用。

  1. 1

    安装 Tampermonkey

    为 Chrome、Edge 或 Firefox 安装 Tampermonkey 浏览器扩展。

  2. 2

    下载并安装脚本

    点击下方按钮下载 zip 并解压，打开其中的 .js 文件复制全部内容；在 Tampermonkey 中「新建脚本」，全选替换后保存（Ctrl / ⌘ + S）。

  3. 3

    打开腾讯会议，开始导出

    进入腾讯会议网页版的会议纪要 / 字幕页面，悬浮面板会自动出现。点击「读取字幕」，完成后即可导出或复制。
